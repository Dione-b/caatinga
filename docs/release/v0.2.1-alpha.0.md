# Caatinga v0.2.1-alpha.0

## Status

Alpha. APIs, config format, artifacts format and package exports may change before v1.

## Packages

- `@caatinga/cli@0.2.1`
- `@caatinga/core@0.2.1`
- `@caatinga/client@0.2.1`

## Compatibility

- Node.js 20+
- Stellar CLI 23.0.0–25.2.0
- Rust 1.84+
- wasm32v1-none target

## Highlights

- CLI flow: init, build, deploy, generate and invoke
- Network-scoped artifacts
- TypeScript client package
- Browser integration example
- Documented CAATINGA\_\* error codes

## Known limitations

- Alpha stability
- No default mainnet automation
- No multisig flow
- No backend signing abstraction
- No official React hooks yet
